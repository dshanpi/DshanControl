# T113s4 原生只读监督 · 2026-10-15

系统 C++ 服务新增显式启用的监督模块和 `service.health` 查询。独立助手进程执行
原生应用健康检查，避免后端超时阻塞 RPC；输出及执行时间有上限。连续失败达到配置
阈值时返回告警，保留原始错误阶段/代码。监测不发送应用信号、不重启或重装应用，
不写应用数据库，也未接管硬件看门狗。

监测前后读取内核 `/proc/locks`，按锁文件设备号和 inode 判断更新/控制资源忙碌，
不申请这些锁。期间版本链接或提交变化时丢弃观察结果。这里是只读状态观察，不是
维护授权或安装健康验收的替代。锁记录格式核对了选定 Linux5.4 的 `fs/locks.c`。
状态保存在服务内存，服务重启后重新检查，不宣称历史告警持久化。

缺省监督关闭。生产启用必须使用私有启动记录和原生系统监督角色；配置字段、类型、
周期和阈值有明确限制。健康检查助手仅继承固定最小环境，退出或超时只处理该助手。
