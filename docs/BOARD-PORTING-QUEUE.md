# DshanControl 后续主板适配队列

2026-10-14 用户补充：IMX6ULL-PRO、STM32MP157、RK3506。
既有后续目标 A133、T527、RK3576 同样保留。

除下面单列的 6ULL 开发接入外，其余目标当前仍待适配，不声明已支持。接入时分别固定实际板卡/修订、
厂商 BSP/SDK、存储/分区、架构/浮点 ABI/libc、运行库、显示/输入、网络及工业接口。
共用平台接口和应用更新协议；各目标包、系统来源、实板证据分别维护。
不得借用 T113s4 的设备树、分区、Loader、GPIO 或二进制来推定兼容性。

顺序：先完成 T113s4 系统平台与更新基础设施，保留 T153 回归，
之后按实际可用硬件逐板接入。具体接口/型号/容量未知时保持待确认，拒绝发布支持声明。


2026-10-22：IMX6ULL-PRO 已在独立 `6ull` 分支完成 Lite 开发移植和屏幕、触摸、
Wi-Fi、本地软件视频的实板功能验证，见 [开发验收](IMX6ULL-DEVELOPMENT-20261022.md)。
PCB 修订、权限隔离、签名更新、维护互锁、升级中断/回退与长期运行仍未资格验收；
中央板型登记为 `candidate_profiles: [lite]`，`supported_profiles` 保持空数组。
