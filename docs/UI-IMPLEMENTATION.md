### 字体与资源

`visuals.cpp` 实现矢量绘制及总览数据绑定。应用内嵌 Dshan Sans Regular/Bold，
为 Noto Sans CJK SC 的 GB2312、Latin 和界面符号子集；约 7.1 MiB。
开发机及板上加载同一份字体，系统文泉驿可补充子集外字符。

字体遵循 OFL-1.1，已附原许可并重命名字体族。S4 应用包和 T153 安装规则
随附字体许可。`fonts/manifest.json` 记录原 TTC 与产出哈希及 FontTools 版本；
`scripts/build_hmi_fonts.py` 提供重建方式，保留源字体时间戳，避免重建时引入当前时间。
图标由 QPainter 绘制。字体及图标均不依赖网络服务。

## 真实数据与功能边界

- 总览数据来自 `/api/hmi/v1/snapshot`。不把模块数量、设备地址、签名状态等
  设计样例硬编码为真实读数。暂无字段时显示未知、未配置或等待数据。
- 趋势按“温度/压力”名称绑定，kPa 显式转换为 MPa，横轴为最近 60 秒；
  同一时间点替换，时钟倒退清空旧曲线，超出窗口的数据移除。
  纵轴随超量程读数扩展，缺测/离线清空，不将过期曲线继续显示为当前状态。
- 保留板级能力禁用、危险操作确认、设置编辑保护和按 ID 维持告警选择。
  筛选隐藏已选告警时清除选择，确认操作再次检查可见性。
  CSV 只导出当前可见记录，使用原子保存、引号转义和公式前缀防护。
- 效果图中寄存器明细、EtherCAT 从站及抖动曲线、网络静态配置尚无完整后端
  接入，界面明确显示空态或只读信息，不绘制虚构的硬件数据。
- 更新页调用已有系统更新器执行兼容检查。只有发布清单通过检查后才显示
  相应结果；“清单已验证”不代表未下载的应用包内容已经完成校验。
  GUI 安装按钮保持禁用，安装仍需系统维护流程；没有新增图形化安装控制服务。
