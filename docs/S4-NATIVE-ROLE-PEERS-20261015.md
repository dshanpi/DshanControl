# T113s4 原生 IPC 角色授权 · 2026-10-15

新增显式 `s4-roles-v1` 策略。启用生产托管角色时必须选择该策略，系统服务必须由
root 运行，IPC 组固定400、允许 UID 恰为0/400/401，额外或重复 UID、错误组及
未知策略均拒绝。服务继续使用内核 SO_PEERCRED 取得调用身份。

| 角色 | 可用方法 |
| --- | --- |
| root系统所有者 | 系统配置允许的全部原生方法 |
| 网页UID400 | 显示亮度读写、只读健康查询 |
| 界面UID401 | 显示亮度读写、健康、更新身份/状态/任务 |

应用角色不能管理守护进程生命周期；网页服务不能提交更新。方法授权之后仍需各自
参数、维护、签名和兼容性检查。策略不在 RPC 请求中选择，保存在 root 私有配置。
旧配置未启用托管角色时保留已有显式 UID 授权方式。

2项另跑通过。ARM构建通过，实板23项全部通过，12次角色RPC观察。精确结果与哈希见

通过。设备未绑定仍拒绝打开设备，没有放宽显示检查。
