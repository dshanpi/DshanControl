# 筛选、确认并导出告警

在已连接告警后台的设备上处理一条告警，并导出当前可见记录。确认操作会更新告警记录；它不表示设备故障已经排除。

## 1. 选择要处理的记录

进入“全部应用 → 告警记录”，按以下顺序缩小范围：

1. 选择“全部”“未确认”或“已确认”。
2. 在“级别”中选择全部、警告、错误或提示。
3. 选择来源，再选择“全部记录”“最近 24 小时”或“最近 7 天”。
4. 点击一条可见记录，查看下方“选中告警详情”。

核对详情中的 ID、发生时间和内容，确认目标设备与待处理事件一致。时间筛选依赖设备时钟；异常时间应先记录并按[网络与时间检查](network.md)处理。

页签数量统计与当前级别/来源筛选结果可能不同，以实际可见行和详情为本次操作对象。页面加载的是后端返回的记录集合，不能将其视为数据库全部历史。

## 2. 确认选中告警

1. 按现场处理流程核实原因与处理状态。
2. 再次核对详情 ID，点击“确认选中告警”。
3. 等待请求结束，不在等待期间重复点击。
4. 切换到“已确认”或“全部”，查找同一 ID，确认状态已变化。

在“未确认”页签中，成功确认的记录会因筛选条件而消失。这是正常结果，应在“已确认”中核对。

按钮灰色时检查：是否选中可见的未确认记录、后台是否可用、是否仍有确认请求在处理。改变筛选后原选中记录可能被隐藏，须重新选择，不能沿用旧详情。

请求中断或结果未知时，先刷新并读取同一 ID 的状态。记录可能已经更新，不能仅凭连接错误判断未执行。

## 3. 导出当前可见记录

1. 设置需要的状态、级别、来源和时间筛选。
2. 检查当前可见行是否符合导出范围。
3. 点击“导出记录”，选择保存目录和 CSV 文件名。
4. 等待“导出完成：当前可见告警已保存”。
5. 打开文件，核对 ID、时间、级别、来源、内容和状态。

导出范围在打开保存对话框前固定。它导出的是**本次页面中符合筛选的记录**，不执行额外的全量数据库查询。CSV 使用 UTF-8 编码并带 BOM，适合在支持该编码的表格工具中打开。

若弹出导出失败，先检查保存目录和磁盘空间；不要仅凭文件存在判断完整。取消保存对话框不会生成一次成功导出。

## 4. 复核与归档

在记录中保留：应用/系统版本、筛选条件、告警 ID、处理人、处理时间、确认后状态及导出文件名。导出内容包含现场信息，分享前按需要脱敏。

需要数据库一致性备份时，使用[SQLite 备份流程](configuration.md)，不能用 CSV 替代完整数据库，也不能把运行中单个 `.db` 文件的复制当作一致备份。

| 异常 | 处理方法 |
| --- | --- |
| 没有记录 | 放宽筛选，检查演示开关、时钟和后端返回范围 |
| 已选记录突然消失 | 检查筛选条件及是否已被确认；重新查找同一 ID |
| 确认按钮不可用 | 检查选中状态、后台连接和正在处理的请求 |
| CSV 少于预期 | 核对页面可见范围及后端加载限制，必要时由管理员按数据保留策略导出 |

技术依据：[告警筛选与 CSV 导出](../../components/hmi/src/mainwindow.cpp)、[告警确认事务](../../components/web/hmi_api.py)。
