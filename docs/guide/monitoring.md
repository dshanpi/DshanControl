# 检查读数来源并查看趋势

通过“运行总览”和“设备监控”判断当前系统与采集数据是否有效。前提是相应 Web API 或桌面数据服务已接入；没有外部设备时，只检查主机实际能够提供的系统指标。

## 1. 先检查总览状态

从“全部应用 → 运行总览”进入页面，先看接口和数据来源，再看数值。CPU、内存、存储等系统指标与外接传感器属于不同数据源。

对照以下记录逐项检查：

| 检查项 | 应记录的内容 |
| --- | --- |
| 对象 | 系统指标，或具体设备/点位 |
| 数值 | 当前值、单位、量程和显示精度 |
| 来源 | 设备真实返回、样例或尚未获取 |
| 时效 | 最近更新时间，是否持续刷新 |
| 质量 | 有效、缺测、过期或离线 |

真实采集验证应关闭演示数据，并确认显示来源。演示开关不会使真实设备上线，也不能作为控制操作的隔离措施。

## 2. 查看设备监控页

1. 打开“全部应用 → 设备监控”。
2. 查看顶部读数与数据状态，再检查“数据点”表中的名称、当前值、单位和状态。
3. 观察“最近 60 秒”趋势，确认变化与实际采集过程一致。
4. 对照一个已知参考值，例如设备自身显示值，核对单位、比例和变化方向。

没有采集读数时，页面可显示“尚未获取采集读数”。先检查数据源与映射，不将空表或 `--` 记录为零值。

## 3. 暂停和恢复显示

点击“暂停监控显示”，按钮变为“继续显示 · 当前已暂停”，当前页面的读数和趋势冻结。现场采集、告警与其他页面仍继续刷新。

再次点击后，页面使用最新快照恢复显示。恢复时开始新的趋势片段，避免把暂停期间没有显示的数据连接成连续曲线。需要改变刷新速度时，进入“刷新与显示设置”，按[显示设置](settings.md)保存。

## 4. 查看绑定点位趋势

从工作台趋势组件进入时，页面使用组件保存的设备/点位标识。检查主点位、第二点位（如已绑定）、单位和质量是否仍与组件一致。

数据源离线或点位暂时缺失时，应保留绑定并显示缺测。若需要换点位，返回[组件编辑](widgets.md)明确重新选择，不以其他点位自动替换。

## 5. 判断异常读数

| 现象 | 先检查什么 | 继续条件 |
| --- | --- | --- |
| 显示 `--` 或缺测 | 采集服务、点位映射、消息格式 | 收到该点位有效样本 |
| 数值长时间不变 | 更新时间、设备本身是否变化 | 有新的采集时间或已确认被测量稳定 |
| 数值有变化但比例不对 | 单位、倍率、寄存器字节序 | 与独立参考读数一致 |
| 离线后仍有旧值 | 质量和时效标记 | 恢复新数据后再使用 |
| 显示样例 | 演示设置和数据来源 | 关闭样例后取得真实数据 |

MQTT 数据接入采用显式主题与点位映射；保留消息不会被当作实时采样。开发接入时应同时传递身份、单位、时间和质量，见[接口参考](api.md)。

## 完成检查

至少选择一个真实点位，记录来源、单位、当前值与更新时间；验证暂停仅影响本页显示，恢复后能继续接收新数据。发生告警时，继续[筛选并确认告警](alarms.md)。
