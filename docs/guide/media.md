# 选择媒体并检查播放状态

**适用对象：** 使用已集成媒体后台的设备用户。桌面显示媒体卡片不代表解码、显示和音频链路已验收。

## 准备文件

默认媒体目录为 `/mnt/UDISK/media`，可通过 `DSHANCONTROL_MEDIA_DIRECTORY` 指定。使用设备上真实存在、运行用户可读取的本地文件。主机上的路径不会自动映射到板端。

不要只改扩展名来“转换格式”。具体容器、编码、分辨率和音轨能力由目标媒体后端决定，先用已知兼容的小文件建立基线。

## 播放步骤

1. 打开“视频播放”，进入“本地视频”。
2. 选择文件，核对标题和路径。
3. 回到“正在播放”并启动播放。
4. 等待真实播放状态，再测试暂停、继续和定位；不支持的操作以界面状态为准。
5. 结束播放后检查退出结果，再切换应用。

从工作台视频组件进入时，绑定只负责定位文件，仍需在播放页点击播放。

## 分开判断四件事

| 现象 | 说明 |
| --- | --- |
| 文件能被列出 | 路径和文件发现链路成立 |
| 请求被接受 | 后台收到了播放请求 |
| 图像和声音正常 | 解码、显示和音频至少在本次场景可工作 |
| 停止/切页后资源释放 | 生命周期验证成立，需要单独观察 |

某一次视频播放正常不代表所有格式、连续切页和长期运行都通过。Cedar、目标显示适配和 Qt 私有 ABI 必须与系统匹配。

## 常见问题

- **文件列表空：** 核对媒体目录、挂载点、文件权限和实际路径。
- **画面黑但进程存在：** 查看媒体会话错误和目标显示链路，不能用 PID 存活当播放成功。
- **有图无声：** 查看音轨格式与 ALSA 设备；按本板资料诊断。某块板的临时采样率配置不能作为所有板的通用修复。
- **停止后一直忙：** 保留错误与会话身份，先查资源释放；不要重复启动多个播放器或强制改系统库。
