# 使用 CAN、Modbus 与 EtherCAT 页面

**适用对象：** 已有对应物理接口和测试从站的集成人员。页面入口存在不表示本板具备该总线；S4 不能沿用 T153 的设备节点和接口声明。

## 操作前准备

核对板级接口、收发器、隔离和接线；从设备手册取得通信速率、节点地址、寄存器/对象字典。先断开危险执行负载或进入真实维护状态，再进行会改变设备状态的命令。界面确认框不替代现场维护许可。

## CAN / CANopen

1. 打开“现场总线 → CAN / CANopen”。
2. 查看接口表的链路、速率和来源，选择实际枚举出的接口。
3. 输入与网络匹配的仲裁速率。源码校验范围是 `10000..1000000` bit/s。
4. 只有硬件和平台声明支持 CAN-FD 时才启用；数据速率不得低于仲裁速率且不超过 `8000000` bit/s。
5. 点击“应用配置”，核对目标接口和参数，确认后等待结果。
6. 再读接口状态，确认配置生效；配置成功仍不等于从站互操作成功。

源码默认显示的 `500000`、`2000000` 是表单初值，不是任何现场网络的推荐配置。

### NMT 与 SDO

NMT 页发送节点状态命令，SDO 写入页根据节点、索引、子索引和值访问对象。先查从站字典的类型、范围及访问权限，不能把任意示例索引直接写入设备。收到失败或结果未知时，先读取实际状态和日志，不连续重复控制命令。

只读诊断可在设备执行：

```bash
ip -details link show
```

未出现 CAN 接口时检查驱动和板级配置；出现接口但无从站响应时检查终端电阻、接线、速率和节点。不要把“接口 up”当作现场通信通过。

## RS485 / Modbus

1. 打开“RS485 / Modbus”，核对可选串口来自本板能力清单。
2. 按从站手册填写串口、波特率、站号与轮询周期。
3. 保存配置，检查动作结果和后续采集状态。
4. 用一个已知只读点位核对数值、字节序、单位与变化趋势，再逐步扩展。

串口节点存在不代表电气层是 RS485。校验位、停止位、寄存器映射等高级配置须按采集后端和现场设备手册设置，不能假定页面已覆盖所有协议参数。

## EtherCAT

1. 确认专用接口、主站工具与从站链路可用，避免把正在承载远程维护的网口直接改作测试总线。
2. 在 EtherCAT 页查看从站信息及可用操作。
3. SDO 写入前核对从站、索引、子索引、长度及允许状态。
4. 周期测试只在允许的隔离环境运行，保存周期诊断与错误信息。

“未测量”表示还没有有效诊断结果。主机回归、SOEM 工具存在、扫描到从站、周期通信通过和控制系统实时资格是不同层次。

## 本页完成标准

每条记录至少包含：板卡/系统身份、接口、从站型号、参数、命令结果、读回值和日志时间。没有外部从站时只能记录页面和软件校验结果。
