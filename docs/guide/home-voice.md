# 使用家庭设备与语音入口

**前提：** 已安装匹配后台，并完成对应家庭网关或语音服务授权。公开源码提供接口和页面，真实账号、设备及麦克风链路仍须实际接入。

## 家庭设备

1. 从应用抽屉打开“家庭设备”。
2. 查看授权状态；未授权时先由管理员配置受限账号凭据。
3. 点击“同步设备”，等待设备列表和房间信息返回。
4. 选定房间，再选择具体设备，核对名称、在线状态和属性。
5. 仅对界面提供的可写属性操作。布尔、枚举和数值属性遵守服务返回的类型与范围。
6. 点击“设置此项”后等待真实结果，再核对设备状态。

服务端授权必须限制到所需家庭与设备。云官网绑定不会自动授权家庭账号。离线、过期或只读属性不能被当成可控制入口。

### 结果不确定时

网络中断可能发生在命令已经发出之后。先同步设备状态并查看结果，不连续重复点击。源码采用一次性上传和幂等标识来约束命令，但端到端效果仍取决于网关及真实设备。

## 语音对话

1. 打开“语音对话”，先看服务是否已接入和就绪。
2. 选择“按住说话”模式，按住按钮开始监听，松开结束监听。
3. 根据需要切到“连续对话”，注意它与按住模式的生命周期不同。
4. 点击“结束对话”终止当前交互，再退出页面。
5. “清空对话记录”清理本次会话显示；不要把它当作删除外部服务已有数据的证明。

页面说明语音会发送到配置的涂鸦服务，对话记录只保留在本次会话内。使用前确认所接服务和账号适合当前场景。

## 如何验证

UI 测试可检查按钮与请求的对应关系。真实语音验收还需麦克风输入、识别、播报、停止/退出后的资源释放；家庭控制需核对真实设备读回。固定截图、模拟 socket 和测试成功不能替代这些步骤。

常见异常：同步失败先查授权和网络；设备离线先查网关；按住无反应先查语音服务就绪与音频设备，不直接替换系统音频库。
