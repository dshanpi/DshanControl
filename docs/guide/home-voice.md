# 同步家庭设备并使用语音对话

本页分别说明家庭控制和语音操作。两者使用桌面接入服务，但各自需要独立的网关授权或语音运行时。官网绑定不能替代这些条件。

## 1. 准备家庭接入

管理员需配置可用的家庭网关 HTTPS 地址及受限授权 token，并确认授权范围包含所需家庭、设备与操作。配置方法见[后台配置](configuration.md)。

进入“全部应用 → 智能家庭”。若显示“接入服务未连接”，先检查服务；若显示家庭账号未授权，先处理授权，暂不发送控制。

## 2. 同步并选择设备

1. 点击“同步设备”，等待设备和房间信息返回。
2. 从“全部房间”切换到目标房间。
3. 选择设备，核对名称、在线状态和右侧“设备控制”。
4. 检查属性名称、设备回报值、可写性及允许范围。

从工作台绑定组件进入时，应定位原设备。提示绑定设备暂不可用时，先同步并核对设备身份，不自动改选另一设备。

## 3. 修改一个可写属性

按设备返回的类型使用对应控件：布尔属性使用开关，枚举选择允许值，数值按范围和步长输入。需要“设置此项”的控件，输入后点击该按钮；确认框中再次核对设备、属性和值。

确认发送后等待请求结果，再查看设备回报值。不能只根据开关移动、输入框内容或“请求已受理”判断实体设备已经变化。

设备离线、状态过期、授权改变或属性只读时，应停止提交并同步最新状态。连接在发送后中断时，先查真实设备和网关结果，避免连续重复控制。

## 4. 准备语音服务

打开“全部应用 → 语音对话”，检查服务就绪状态。需要已配置语音运行时 socket 和身份，并完成激活、麦克风输入与扬声器输出集成。

页面显示“激活与录放音已就绪”后才开始语音操作。语音会发送到已配置的涂鸦服务，应使用适合当前场景的账号和环境。

## 5. 执行按住说话与连续对话

**按住说话：**

1. 在“对话模式”选择“按住说话”。
2. 按住说话按钮，确认状态进入监听。
3. 说完后松开，等待识别、处理和回复。
4. 核对实际识别内容、响应和音频输出。

**连续对话：**

1. 切换到“连续对话”，等待服务进入对应状态。
2. 按服务提示对话，观察监听、处理和回复过程。
3. 完成后点击“结束对话”，确认交互结束，再离开页面。

切换模式、服务失去就绪状态和离开页面都涉及会话结束处理。验收时应确认实际录放音已停止，不能仅凭按钮恢复初始外观判断。

## 6. 清理显示记录并处理异常

“清空对话记录”清理本次服务会话中的记录，不证明外部服务已删除其数据。需要外部数据管理时，按服务方提供的机制处理。

| 异常 | 下一步 |
| --- | --- |
| 家庭列表为空 | 检查授权范围、同步结果、家庭归属和网关 |
| 属性不可写 | 核对属性 schema、授权、设备在线与新鲜状态 |
| 控制结果未知 | 读取设备和网关实际结果，保留请求时间 |
| 语音未就绪 | 检查运行时身份、激活与音频设备 |
| 有识别无播报 | 检查扬声器、音频输出路由和运行时错误 |

完成标准：家庭控制有实体设备读回；语音完成输入、识别、回复及结束后的资源检查。UI 模拟请求仅用于软件验证。
