本手册针对公开应用基线 `6c7a5e382fd44c159eeec71b7a19af67498f589e` 编写，内容核对日期为 **2026-11-12**。后续纯文档提交不改变这一应用基线。

## 1. 对应正在使用的版本

在源码仓库用 `git rev-parse HEAD` 取得完整提交；设备运行版本按应用包清单和交付记录确认。若版本不同，先核对相关界面、参数和服务合同再执行操作。

主机快速开始使用 Qt5；目标 S4 构建使用对应 SDK 和目标 Qt。二者结果不能混写为同一环境的验证。

## 2. 区分可复现范围

| 范围 | 本手册提供内容 | 需要的环境 |
| --- | --- | --- |
| Ubuntu 主机 | 编译、固定图渲染、桌面导航、布局、IPC 实验和测试 | 主机依赖；交互另需图形会话 |
| 已集成设备 | 各页面操作、检查方法和故障处理 | 匹配系统、服务、配置及权限 |
| 外部业务 | 总线、云、家庭、语音和媒体的前提与步骤 | 真实接口、从站、账号、音频和目标解码能力 |
| 系统交付 | 用户态构建、更新边界和验收记录 | SDK、系统构建及真实硬件验证 |

公开版定位为源码预览。具备页面和软件接口不表示所有目标硬件、外部服务或生产更新已经完成资格验证。

## 4. 识别当前页面限制

- Modbus 页面保存首个从站参数，运行生效需要采集系统另行确认。
- EtherCAT 明细与部分诊断展示尚有占位，须结合工具结果和独立读回。
- 媒体硬件解码依赖目标系统，普通主机构建不能替代板端播放。
- 真实云/家庭/语音、物理显示/触摸/音频、更新恢复和持续运行需要独立验收。

具体影响在对应操作步骤旁说明。遇到不满足的前提时先补齐条件，再执行后续动作。
