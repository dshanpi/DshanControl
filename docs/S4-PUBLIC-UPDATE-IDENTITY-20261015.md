# T113s4 界面公开更新身份查询 · 2026-10-15

原生启动器通过公开 socket 环境选择系统服务。Qt 更新页使用
`update.identity` 查询当前版本、系统身份及布尔型 `check_configured`，不读取 root
私有 updater.json 或签名公钥。系统仍负责后续签名、兼容性、维护及安装验证；公钥
文件可用仅表示检查配置存在，不代表候选更新已通过校验。

身份未就绪时，点击检查只重新查询身份；不会提交检查、下载或安装任务。缺失或类型
错误的就绪字段不授予检查能力。安装完成后只刷新身份，不反复恢复同一完成任务。
旧版非原生 T153 路径保留原有本地身份发现方式。

Qt 测试覆盖私有配置不存在、未配置公钥、错误布尔类型、任务恢复、安装后刷新及
失败原始阶段/错误码。另以真实非 root 客户端连接 root 服务：UID60001 能读取身份
和任务状态，不能读取测试私有配置或操作服务生命周期；UID60002 被拒绝。
这些数字 UID 仅用于隔离测试，没有创建账户。

初轮 ARM17 中，真实非 root 客户端及存储拒绝用例通过，其余15项因测试临时目录
过长而无法创建 Unix socket。保留该轮完整失败证据；测试改用 /tmp 下的私有随机
目录后，用相同运行时二进制复测17项全部通过。主机完整224项（3项root专项跳过）、
Qt37项通过；新增root客户端专项另行运行通过。精确结果与哈希见
[结构化回执](validation/2026-10-15-public-update-identity.json)。

实际板上的工厂应用、系统账户、设备权限、启动配置和签名信任根未改变。新运行时
与 HMI 均已按 S4 sysroot 交叉编译；此处没有宣称新 HMI 已在屏幕上验收。
账户与数据/设备权限、原生监督和真实 Qt 签名更新仍需继续完成。
