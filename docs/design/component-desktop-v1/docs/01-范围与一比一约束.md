# 01 范围与一比一约束

## REQ-SCOPE-001 产品结构

实现 Qt5 原生工业控制桌面壳：顶部信息栏与下拉控制中心；中部可配置组件工作台；底部上拉所有应用。替换旧桌面的导航组织，保留现场总线、网络、设备、告警、设置和应用更新能力。应用抽屉是功能启动入口，**本期没有应用商城、支付、在线任意安装或新的 OTA 协议**。

工业蓝白风格、1024×600 横屏 RGB50 主基准。使用 Qt Widgets / QPainter；保持现有 C++11 / Qt5 工具链，最低目标兼容 Qt5.11.3，参考主机 Qt5.12.8。不引入 Qt6、WebView、Electron、浏览器壳。当前 HMI `.pro` 使用 core/gui/widgets/network，图形为自绘，不以 QtCharts 安装作为前提。

## REQ-VIS-001 视觉契约及优先级

静态外观优先级：用户认可的本包 PNG → 同包参考渲染源码 → 几何/令牌 JSON → 文字解释。业务真实性、安全控制、平台权限和更新边界不能为了仿照示例假状态而被绕过。有冲突须记录差异和修正建议，不由开发者自行换风格。

锁定：顶部高 53、外边距 24、组件间距 16、卡片 20 圆角、原字体、24 基准线性图标、图文对齐、背景渐变、抽屉尺寸、遮罩层级。所有值均以 1024×600 的逻辑像素为准。禁止改成左侧导航栏、常驻大 Dock、黑色大屏、密集表格主页或普通网页仪表盘。

不允许把原本不透明的卡片改成透出后面文字的玻璃效果。背景允许原稿的渐变和低透明光晕；面板内容底色固定不透明白。禁止用字体符号/Emoji 替换已提供 QPainter 图标路径。

## REQ-VIS-003 验收模式与真实运行模式

`visual_fixture`：严格使用原图文案、时间、假曲线、图像裁剪和控件状态，禁发现场控制/云写入/系统操作。用于可重复的视觉验收。01～09 每张图必须能稳定重放。

`runtime`：使用真实时钟、连接状态、点位、媒体和告警。标题、位置、字号等不变；“示例预览”区域替换为“运行状态”或真实离线/维护状态；脚注替换为产品/当前状态，保留原文字区域。不能把“示例数据”“设计入口”等遮掉后继续展示假数据。缺数据显示“-- / 暂无数据 / 服务未连接”，不得填充演示数据。

“一比一”的完成条件：固定环境固定数据逐像素无差异；不同 Qt/FreeType/板端渲染栈导致的文字抗锯齿差异必须独立记录、建立对应环境基线并人工确认，不能自动当通过。不能用 95% 相似度或全局 SSIM 分数替代控件逐项验收。

## REQ-SCOPE-002 现有能力保护

保留原六类应用全部子页和动作：CAN 配置、CANopen NMT/SDO、RS485、EtherCAT、以太网/Wi-Fi/蜂窝、设备点位、告警确认、显示和服务管理、审计、应用更新。入口变更不能删除原功能。按实际 board capability 控制操作是否可用。

云端、上报、语音、家庭、视频均在新桌面列出；运行接入不完整时保留准确的不可用状态，不显示为已经工作。真实硬件解码、音频、家庭控制与云端连接需另外实测；本包不冒充这些验收证据。

系统启动、内核/DTS、分区、板标识、信任根和系统更新器不属于桌面改版。仍是已有 T113s4 SD NAND 路线，不能把 SDK 当前通用 t113/evb1_auto_nand 配置误当已正确选板。桌面改版按应用发布边界组织，不自动重编/刷写整个 SDK。
