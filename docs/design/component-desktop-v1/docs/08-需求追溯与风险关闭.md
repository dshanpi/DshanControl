## 集成前必须关闭的差距

1. 现有主程序默认字体不是Dshan Sans：必须加载本包字体并回归中文。仅改QSS颜色无效。
2. 整理过程中其他工作已把DesktopClient/CloudPanel/FamilyPanel/MediaSession/MediaPanel加入HMI构建及旧导航：末次快照已更新。新桌面直接复用，补section/媒体文件路由适配；不重复实现，不把源码接入称为真机完成。
3. 环境温湿度没有可直接复用的系统history接口：使用真正点位并积累本地曲线；没有采集时显示空。
4. 当前预览只做了有限swap/remove/add展示：需要完整草稿、兼容槽、持久化、取消及错误处理。
5. 预览detail多数入口都显示温度图：必须替换成真实路由，不照搬这个简化行为。图06只约束设备监控展开样式。
6. 预览亮度点击仅切45/72：需真slider与已存在保存/硬件调用链；“通知声音”另需应用通知音能力状态。
7. 预览小图片分支画了语音波形：图片实现遵循图09大图片模板和实际解码，不复用该假分支。
8. Cedar视频层能否被Qt面板正确覆盖尚待目标板验证：先用静态海报，完整视频必须实现visible/rect生命周期。
9. 新服务socket、数据目录、应用worker打包和权限需纳入实际生命周期；不要临时chmod777或让GUI提权掩盖安装缺口。
10. 带软键盘、空态/错误、绑定选择、编辑取消确认等没有在现有10图全覆盖：本包规定行为和tokens，实施时补同风格截图；不得把这些称为已认可像素基线。

## 变更纪律

用户明确要求新图一比一优先于旧桌面的视觉偏好；但旧功能/数据权限/升级边界持续保留。任何需要改变已批准画面的提议，应提供原图、候选图、差异区域、原因和影响，不能悄悄替换reference/screens。纯动态文本、真实缺数据状态按已定义runtime变体处理，不需要每个时钟数字都审图。

记录“实现完成”“主机验证”“交叉编译”“真机通过”四种不同状态。本包交付只完成需求包整理与参考复现，不挪用历史板端通过记录证明新桌面已上线。
