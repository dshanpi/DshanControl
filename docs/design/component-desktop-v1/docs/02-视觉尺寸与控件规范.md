## REQ-VIS-010 坐标与绘制

坐标原点为窗口左上，矩形顺序 `[x,y,width,height]`。基准 DPR=1，不含窗口标题栏/边框。`contracts/visual-tokens.json` 和 `geometry.json` 给出主要参数；每段文字、曲线、图标路径的最终依据为 `reference/source/desktop-preview.cpp`。QPainter 开启 Antialiasing 和 SmoothPixmapTransform，文字使用 pixelSize，禁止误用 pointSize。

图标：源坐标24×24、线宽1.65、圆端圆连接，按实际size/24缩放；图标函数覆盖 chart/wifi/bus/device/bell/cloud/upload/video/image/home/mic/settings/update/sun/grid/plus/up/down/back。直接复用路径；不要换一套图标库。

## REQ-VIS-016 文本与触摸

交互有效区最小44×44逻辑像素；多邻接目标不得重叠，目标以最上层/专用子控件优先。视觉小胶囊不代表可点击，未标为操作的状态标签不设假按钮。中文长名称单行省略，详情可看全；数值超长改科学计数或指定有效位，不能挤掉单位；错误两行以内摘要，详情页面展示原因。空态/加载/错误仍在原卡片内部布局，不挤走邻居；新增交互视图须沿同套tokens并补截图，不能宣称已在10图中审批。
