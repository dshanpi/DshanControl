# 07 验收与交付

## REQ-QA-001 视觉验收

1. 不修改reference/screens，先执行verify_package.py锁定哈希。
2. 在Ubuntu同一Qt5.12.8、DPR1、字体、offscreen绘制环境运行tools/render_reference.py。参考重建只替换绝对资产路径，不改变绘制代码。
3. 使用compare_render.py比较候选输出和10张原图。比较尺寸和RGBA每个像素，任意不同非零退出；生成每图changed_pixels/max_channel_delta/差异边框数据，不自动放宽容差。总览额外计入，但不能代替单屏通过。
4. 生产HMI增加独立fixture入口，使用同一组件和layout代码，输出相同命名截图；禁连接真实控制写接口。参考重建通过只说明参考包可复现，**不能算生产实现验收通过**。
5. 每个页面人工检查图标、中文、字重、基线、对齐、阴影、圆角、间距、遮罩、层级、无裁切。静态全图不得遮罩忽略大块动态区域；fixture本来就应固定动态数据。
6. 真机有不同字体栅格化时记录环境差异和差异图；布局边缘误差目标0，测量最多1物理像素的边缘定位差须逐项解释，不能批量豁免。字体抗锯齿差异单独评审，不改参考图迎合错误实现。

命令在需求包根目录执行：

```sh
python3 tools/verify_package.py
python3 tools/render_reference.py --output /tmp/dshan-desktop-reference
python3 tools/compare_render.py reference/screens /tmp/dshan-desktop-reference/renders --report /tmp/dshan-desktop-compare.json
# 正式HMI具备截图能力后，将第二个路径换成正式HMI的fixture输出目录。
```

依赖：Ubuntu上的Python3、Pillow（已有）、qmake Qt5、make和C++编译器。工具默认生成到/tmp，不修改SDK构建配置，不调用业务接口。输出目录不得选择本包reference/screens。
