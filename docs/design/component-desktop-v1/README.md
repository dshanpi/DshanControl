# DshanControl Qt5 组件桌面 · 一比一实现需求包 v1.0

交付日期：2026-10-16。目标环境：Ubuntu 虚拟机 `192.168.1.199` 的 T113 Tina SDK，以及 DshanControl 的 T113s4 SD NAND / Qt5 原生 HMI。用户已认可的新桌面效果图为本包视觉基准。

**实现必须与本包已认可效果图一模一样，不接受换一套布局、换字体、换图标、只改配色或“类似效果”。** 本包是设计和实现需求交付，不表示生产桌面已经接入、固件已更新或真机验收完成。

## 从哪里开始

1. 看 `reference/screens/UI新桌面_00设计总览.png`，再按原尺寸打开 01～09 单屏图；总览图不能用作单屏像素基准。
2. 阅读 `docs/01-范围与一比一约束.md`、`02-视觉尺寸与控件规范.md`、`03-页面状态与操作流程.md`。
3. 按 `docs/04-数据与业务规则.md`、`05-真实接口和调用链.md`、`06-Qt5架构与开发任务.md` 实现。
4. 用 `contracts/` 的坐标、应用注册表、布局模型和接口示例进行联调。
5. 按 `docs/07-验收与交付.md`、`acceptance.csv` 验收；执行 `tools/verify_package.py` 检查包完整性。

## 交付内容

|目录/文件|用途|
|---|---|
|reference/screens/|10 张原始 Qt5 原生渲染 PNG，含总览、主桌面、下拉中心、应用抽屉、编辑、组件库、详情、宽屏、搜索、图片页|
|reference/source/|产生已认可效果图的 C++ / qmake 源码；视觉坐标、图标路径和静态绘制顺序的完整依据|
|assets/fonts/|原稿 Dshan Sans 两种字重及 OFL 字体许可|
|assets/media/|原稿使用的播放器示意图；裁剪区域已记录，不是视频解码截图|
|docs/|范围、逐控件规格、业务流程、真实接口、开发拆分、验收与追溯|
|contracts/|机器可读颜色/几何、应用表、布局格式、请求示例、新增 C++ 接口草案|
|acceptance.csv|可逐项填写的验收清单；未做的真机/生产测试保持 NOT_RUN|
|tools/|包校验、参考程序重建、逐像素对比工具|
|evidence/|读取时的工作区状态、相关源文件哈希/符号位置、需求追溯、参考程序复现结果|
|manifest.sha256.json|包内文件 SHA-256 清单；自身除外|

## 强制执行顺序

先冻结并复现效果图，再接真实数据，再接操作和持久化，最后交叉编译及真机验收。生产程序与参考渲染必须共享同一套绘制几何/字体/图标规则；禁止另做一个“截图专用皮肤”掩盖生产差异。

**视觉基线不等于业务实现。** 预览程序中的假曲线、固定时钟、点击切换亮度、通用假详情、简单位置互换，均不能作为生产业务实现复制。真实业务状态替换示例文案，不改变视觉骨架。新增业务函数在文档中标为“新增”，现有函数标出真实路径及访问范围。

包实际放置位置：`/home/ubuntu/T113-tina5v1.2-sdk/DshanControl-Qt5-组件桌面一比一需求包-v1.0/`。SDK 根目录原有 10 张 `UI新桌面_*.png` 保留。无需 Windows 开发环境。
