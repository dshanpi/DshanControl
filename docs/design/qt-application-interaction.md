# Qt 应用交互规范

本规范适用于 DshanControl 的全部应用、子页面和弹窗。优先解决“操作难找、层级不清、反馈被覆盖”，不能只修改首页或颜色。

## 来源与适配
参考 [VoltAgent awesome-design-md 的 IBM 分析](https://github.com/VoltAgent/awesome-design-md/blob/3b605329240ce735b510037cca322f1831fdd7f8/design-md/ibm/DESIGN.md)，固定版本 3b605329240ce735b510037cca322f1831fdd7f8。原文是 IBM 营销网站分析，采用 MIT 许可；它并不是官方 Carbon 产品规范，也没有提供 Qt 组件。本项目借鉴其中的克制、网格、蓝色主操作和清晰层级，再针对 Qt5、中文、1024×600 和触屏制定交互约束。来源许可见 references/ibm-design-license.txt。

## 布局与操作
- 所有应用都有“工作台 / 当前应用”位置提示、“全部应用”和返回工作台入口；应用切换复用注册路由，不暗中触发业务命令。
- 子页用有文字、有选中状态的标签；共享应用内切换绑定/上报、语音/家庭、设置/更新时，位置提示和当前应用必须同步；打开系统设置默认进入设置首页，应用更新从独立入口进入更新页。
- 表单允许滚动，CAN、串口、网络刷新和显示设置的主要操作保持在内容区底部，不随参数一起滚出视野。CAN 只保留一个可滚动内容区，不能通过缩小触屏行高挤布局。
- 页面应回答：当前是什么状态、可以做什么、做完如何确认、失败如何处理。不可操作时显示原因，不能只有灰色按钮或悬浮提示。
- 主操作使用动词和对象：选择视频、播放、发送控制、导出记录。不要让图标、双击、悬停成为唯一入口。
- 视频文件窗口按“视频目录 / U 盘 / 文件系统 → 文件夹 → 视频”浏览，类型和操作全部使用文字。选择后再次核实文件仍存在、可读且不是符号链接。选文件和播放是两个明确步骤；取消文件窗口保留原选择，不开始播放。切出视频应用暂停并隐藏视频；全屏始终有文字“退出全屏”。
- 设置编辑、保存、服务确认分别呈现；云端代理接收不等于云端或设备执行成功。
- 实时连接状态与最近服务反馈分开，下一次轮询不能抹掉操作结果。
- 破坏性或现场控制保留原确认、能力和新鲜状态检查；确认按钮说明执行动作，取消为默认。

## 样式
背景 #f4f4f4，内容面板 #ffffff，正文 #161616，次级文字 #525252，边框 #d0d0d0，主操作/焦点 #0f62fe。错误与警告同时配文字，不只靠颜色。4px 间距基准，主要操作至少 48px 高，边角 0–4px，不用装饰阴影。正文 14–16px，页面标题 22px；继续使用已随应用打包的 Dshan Sans 中文字体。不得换成未交付的字体或网页大标题。

## 页面检查清单
| 应用 | 必须走通的界面路径 | 不得用界面测试代替的证据 |
|---|---|---|
| 运行总览 | 查看状态 → 识别演示/离线 → 进入对应应用 | 真实采集 |
| 现场总线 | 选协议/通道 → 编辑 → 确认 → 查看结果 | 现场互锁及设备响应 |
| 网络通信 | 有线/无线查询；蜂窝选参数 → 确认 → 查看结果/失败提示 | 实际联网 |
| 设备监控 | 列表/绑定点位 → 趋势 → 返回 | 实际点位及持续采样 |
| 告警记录 | 筛选 → 确认 → 结果；导出 → 选位置 → 保存/取消 | 实际告警产生与确认 |
| 系统设置 | 分页 → 编辑 → 保存 → 确认；离开/重进 | 实际持久化与跨启动 |
| 官网绑定 | 查询 → 绑定码/归属 → 过期/失败恢复 | 实际账号归属 |
| 数据上报 | 配置 → 发送 → 等待 → 代理确认/失败 | 云端收到数据 |
| 语音对话 | 能力状态 → 开始/停止 → 反馈 | 真实麦克风、扬声器、服务 |
| 智能家庭 | 选设备 → 功能 → 确认 → 等待设备回报 | 实际设备状态 |
| 视频播放 | 浏览 → 选择 → 播放/暂停 → 子页/全屏 → 返回 | Cedar、实屏、声音 |
| 应用更新 | 检查 → 下载 → 核验 → 安装 → 明确终态 | 合格包、恢复和跨启动 |

## 验证与交付
使用真实 QWidget 页面，主机测试可注入明确标记的合成状态，不能伪造可用服务。每个应用和子页都保存独立截图，另存总览及检查结果。新测试必须针对行为，不只匹配颜色。执行 make test 和 make test-hmi，保留首轮失败及修复后的结果。实机验证依据本轮实际系统身份、维护条件和证据进行；历史接线等待和旧候选状态不得替代当前事实，尚未合格的候选仍不可部署。

## 任务指引与空结果恢复
每个应用提供“使用指引”：开始条件、实际操作顺序、结果确认及失败恢复。指引只解释和导航，不发送控制命令；关闭指引保留当前应用、筛选和未保存编辑。相关入口必须通过已有应用路由。告警明确显示筛选后的条数、空结果原因及清除筛选；零条结果不导出空表。导出冻结记录与条数，离线保留记录须标明最新状态未确认。确认告警只表示知悉，不消除现场故障。设备监控的暂停与设置入口固定可见，暂停仅冻结页面显示。

## 设置编辑与结果恢复
显示设置区分当前表单、服务记录和最近一次保存/背光应用结果。服务记录只表明服务返回的设置，不证明背光实际生效；轮询及撤销表单不能覆盖最近操作结果。撤销需明确确认，只恢复完整有效的服务记录，不发送保存或硬件操作；确认期间服务记录变化、离线或编辑变化必须拒绝。保存期间禁止撤销，保留原有编辑保护与保存后独立背光确认流程。


## 子页面步骤与操作复核

- 顶栏位置和“本页步骤”跟随真实子页：CAN 的 NMT/SDO、RS485、EtherCAT、有线/无线/蜂窝、显示/服务/日志、播放器/文件列表/播放设置、绑定点位趋势与三类告警视图。共享页面跳转须保持应用身份正确。
- 每页显示简短操作顺序；详细步骤说明开始条件、提交方式、结果与恢复。指引只说明或导航，不发送命令；关闭保持编辑和选择。
- 现场、蜂窝与服务控制确认展示本次提交值；确认期间连接变化则拒绝提交。等待确认与等待回复期间不得重复发送，结果保留在原应用并与轮询状态分开。传输失败或无效回复显示结果未确认，不能直接建议重试。
- 操作日志提供触屏可用的“查看选中详情”，详情用纯文本展示，选中记录被筛选隐藏后禁止打开。空记录与无匹配分别说明。
- 控制区和结果区固定可见；重复页标题可以由导航位置承担，以保留触控尺寸和原有小屏滚动限制。实际可视区域、请求计数和能力检查不得因新反馈而削弱。
- 有线/无线页仅查询系统网络服务状态。自动上报开关和周期是即时提交，不能描述为待保存。应用更新不等同系统固件烧写。

## 逐页固定门禁
用户要求先展示 UI 渲染图再实现。执行 [逐页设计与交付门禁](page-delivery-gate.md)，每页独立记录业务流程、操作步骤、功能增减、异常恢复及证据。四组概念总览仅用于方向评审，不能代替单页精修、真实 QWidget 截图或实机验证。
