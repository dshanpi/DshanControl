# DW 趋势展开与告警回看

本轮承接用户“继续优化”，在 DV 已审24页上改进两条具体流程，原人类细节评审 pending 保留。

## P03 绑定点位趋势

默认最近30分钟；点击“展开已有采样”后，主点与对照共用最早至最晚有效历史时间。时间轴标真实时间，各自量程、质量信息及缺测断段保留。“恢复30分钟”立即返回默认视图。单点使用最少1秒显示跨度，仍只绘制一个实际点；无采样明确显示无历史。来源仍是工作台共享缓存，不增加采集请求或第二份历史。

宽屏操作位于绑定摘要旁，窄屏放在摘要下方，按钮至少48px。离线保留已收到历史，当前值不可用，展开不代表新采集或已联网。

## P04/P05/P06 告警记录

确认成功回包后，原流程刷新列表；新增“查看已确认记录”。列表未确认最新状态时按钮禁用。点击仅切换已确认页、保留级别/来源/时间筛选，再按原完整ID和已确认状态唯一匹配。

可见唯一匹配时选中并滚动到该记录；被筛选隐藏时提示清除筛选后回看；未加载或重复ID时不选择其他记录，提示刷新核对。新确认清除旧目标；失败隐藏入口；断线使旧目标失效，断线往返后的迟到回包也不恢复旧入口。确认表示知悉，不表示现场故障解除。原POST/刷新契约、失败反馈及权限保持。

## 其余页面与公共界面

MainWindow/桌面趋势共享构造使24页纳入源码绑定与截图回归；P01、P02及P07—P24无直接业务和布局变化。本轮不扩展现场控制、播放或更新能力，不部署板端。原73项和长期测试资格保持。
