# T113s4 SD NAND 开发镜像与 SDK 差异交付（2026-10-14）

本次交付是 `system` 开发草稿，目标为 `t113_s4/100ask`、SD NAND、TinaSDK 5.0
v1.2、Buildroot、RGB50 1024×600、GT911 与 AIC8800D80。不适用于 T113s3 SPI NAND，
也不代表后续 IMX6ULL-PRO、STM32MP157、RK3506 已支持。

## 交付物

GitHub 草稿 Release 附件提供：压缩厂商格式镜像 `.img.gz`、SDK 输入差异 `.tar.gz`、
工厂预装应用实际源码 `.tar.gz`、122 个 SDK 组件版本锁、原始工厂契约/build-info、
脱敏记录、实板试验记录、`release-lock.json` 和 `SHA256SUMS`。
具体上传位置、资产大小、哈希与回下载验证见
[交付回执](validation/2026-10-14-system-delivery.json)。
厂商二进制只进入授权的 Release 附件，不进入应用 Git。

SDK 差异包包括 9 个组件输入集、67 项跟踪文件变更、36 项内核源码补充、有效板级配置、
内核/Buildroot/BusyBox 配置、打包配置和实际系统覆盖文件。各变更在对应固定基线上
试应用并按文件内容核对通过。它不是完整 SDK；必须另备版本锁对应的厂商源码、工具链与
下载依赖。完整干净重建尚未执行，不能仅凭提交清单宣称完全可复现。

应用仓库另外保留 0001～0005 项最小集成补丁，包括 Boot0 厂商信息门禁、RGB50 触摸、
实际 MMC 容量、工厂 ext4 UDISK 下载以及禁用未使用的 ARISC 打包项。
SDK 差异包保留构建时实际输入；最小补丁是整理后的集成方案，两者不能重复叠加。

## 使用与验收边界

先验证 `SHA256SUMS`，解压 `.img.gz` 后核对 `release-lock.json` 中的原始镜像哈希。
使用已保存板卡/USB 绑定的 LYNX 厂商 FEL/FES 路线；适用性、明确烧录动作、资源锁与
失败不重试门禁不变。此说明不自动触发烧录。

**这是包含空 ext4 UDISK 的工厂整机镜像，烧录会覆盖现有应用和用户数据。**
先备份；不要用它替换现有板上第 6 版试验环境来“保留数据升级”。
镜像未嵌入实验室 WiFi 凭据或设备专用更新签名私钥。启用 FreeRDP 前须逐设备生成证书，
不能恢复厂商共享私钥。GnuTLS 中与公开源码逐字匹配的密码自检向量保留不变。

已完成：容器项边界/哈希、GPT/MBR/下载映射、启动链校验、Boot0 硬件信息、ext4 检查、
私密材料排查、压缩回读与上传附件回下载校验（实际结果以交付回执为准）。
待完成：脱敏副本重新烧录、正式系统契约/签名根、完整实板 OTA 与维护互锁、掉电矩阵、
数据保护和完整干净重建。`automatic_updates_qualified=false`；保持草稿，不公开正式版。
